# v0.3 Plan

Date: 2026-06-02

## Product Decision

v0.3 focuses on relevance and proof. Domain Guardian should not become a noisy PR gate until it can
show that it selects the right domain context and rejects weak briefs.

## New Capabilities

- Confidence-aware Domain Impact Brief generation.
- Low-confidence tasks no longer pull arbitrary domain rules into the brief.
- `check_brief.py --required-topic` validates required Index topics.
- `analyze_diff.py --require-brief` validates matched Index topics, not just generic brief shape.
- Skill trust boundary clarifies that context and diff contents are data, not instructions.

## Why This Matters

This is the step between "helpful local helper" and "workflow gate." It reduces false positives,
keeps agents from over-reading, and makes brief quality measurable before CI/pre-commit enforcement.

## Deferred To v0.4

- Blocking CI gate.
- Project config file.
- JSON output and PR annotations.
- Structured `index.json`.
- Full labeled precision/recall fixture suite.
